# 本地打包 & 提交到 GitHub（不提交 application.yml）

## 一、本地打包与启动

在**本机**项目根目录执行：

```bash
# 方式 A：桌面端一键安装包（推荐，跨机器分发也不用装 JDK）
./pack-sspoffer.sh                # 产出 sspoffer-0.1.0.tgz
npm install -g ./sspoffer-0.1.0.tgz
sspoffer                          # 自动起后端 + Electron 窗口

# 方式 B：直接跑后端 jar（浏览器访问 http://localhost:8080）
./scripts/deploy.sh               # 构建前端 + mvn package，产出 jar
export LLM_API_KEY=你的DeepSeek_Key
export EMBEDDING_API_KEY=你的智谱Key  # 推荐配：RAG Embedding；不配也能启动，只是 RAG 检索降级为关键词
export APP_ADMIN_PASSWORD=你的密码    # 可选
java -jar target/interview-assistant-*.jar

# 方式 C：dev 模式（前后端分离，HMR 热更新）
./dev.sh                          # 一键起 Spring Boot + Electron
```

修改代码后**热更新**生效（不用重新打包），改完直接刷浏览器即可。

## 二、把修改推送到 GitHub

- **一定不要提交**：
  - `src/main/resources/application.yml`（可能含 API Key、密码等敏感信息）
  - `src/main/resources/application-local.yml`（本地个人配置）
  - `.env` / `data/`（运行时数据，已在 `.gitignore`）
- `README.md` / `docs/` 按需提交即可。

### 方法一：先 add 全部，再 reset 掉敏感文件（推荐）

```bash
# 1. 查看当前有哪些文件被修改或新增
git status

# 2. 添加所有改动
git add -A

# 3. 把敏感配置从"待提交"里拿掉
git reset HEAD src/main/resources/application.yml
git reset HEAD src/main/resources/application-local.yml 2>/dev/null

# 4. 确认：Changes to be committed 里不应出现 application*.yml
git status

# 5. 提交并推送
git commit -m "feat: 本次修改说明"
git push origin desktop
```

### 方法二：精确 add

```bash
git add frontend/ src/main/java/ scripts/ docs/ pom.xml         .env.example .gitignore README.md
# src/main/resources/application.yml 不要 add
git status
git commit -m "本次修改说明"
git push origin desktop
```

## 三、每次提交前自检

- `git status` 在 **Changes to be committed** 里**不要出现**：
  - `src/main/resources/application.yml`（含 API Key、密码等敏感信息）
  - `src/main/resources/application-local.yml`（个人本地配置）
- 若不小心已 add：

```bash
git reset HEAD src/main/resources/application.yml
```

```bash

# 1) 安装前后端依赖

# 3) 启动
./dev.sh                                # dev 模式
# 或
./pack-sspoffer.sh && npm install -g ./sspoffer-0.1.0.tgz && sspoffer
```

## 五、在线 IDE 运行代码报 connection timed out

在线 IDE 依赖外部 [Piston](https://github.com/emkcorg/piston)（默认 `emkc.org`）执行代码。若网络受限，可能连不上。

- **超时时间**：默认 30 秒，可在 `application-local.yml` 中调大：
  ```yaml
  piston:
    api-url: https://emkc.org/api/v2/piston
    timeout-seconds: 30
  ```
- **自建 Piston**：如需自建，可起 Docker 容器并把 `piston.api-url` 指到自建地址（参考 Piston 官方文档）。

## 六、简历仅管理员可查看/下载

简历列表、详情、下载、预览接口均已要求**管理员密码**（`APP_ADMIN_PASSWORD`）。未输入正确密码的人无法直接通过网址预览或下载简历。
