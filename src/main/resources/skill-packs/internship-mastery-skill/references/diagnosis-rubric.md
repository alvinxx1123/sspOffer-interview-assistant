# 诊断评级标准

根据候选人对每个概念 probeQuestion 的回答实质判定掌握度等级。

## 三级

- solid（扎实）：能讲清原理 + 自己当时的处理/选型 + 权衡与验证（为什么这么做、有什么代价、怎么验证有效）。
- shallow（浅）：答到一部分，但深度或结构不足——可能知道结论却说不出原理，或讲了做法却没讲权衡，或只背概念没落到自己的项目。
- unknown（不懂）：明显不懂、空答、答非所问、或标注"不懂/略知"且未补充实质内容。

## 判定原则

- 只看回答实质，不因篇幅长就判 solid，也不因简短就判 shallow——一句话答到核心也可 solid，长篇没点到关键仍是 shallow。
- gap 要具体到"缺了哪个点"（如"提到了互斥锁但没说为什么不用逻辑过期方案"），不要泛泛写"深度不足"。
- drillSuggestion 要可执行（如"对比互斥锁 vs 逻辑过期方案、各自优缺点与适用场景，并落到你项目里的热点 key"）。
- 对 unknown 的概念，drill 建议从基础概念入门再递进，不要一上来就问最难的。

## 汇总

- summary：一句话概括整体掌握度（如"6 个概念中 2 solid、3 shallow、1 unknown，优先补强缓存一致性与击穿"）。
- weakFocus：列出 shallow + unknown 的概念名，作为后续施压演练的重点方向。
